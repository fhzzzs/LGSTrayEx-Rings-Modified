# Rings.9 verification

The source implements an experimental in-process XAML Diagnostics provider with positive trailing Start margin, centered Start translation, 2.5-second lease timeout and managed UI Automation clearance validation. This is not a verified Windows release. The Linux authoring environment cannot compile MSVC C++/WinRT or run WPF/Explorer. Automated Windows tests have been added but not run.

See NativeLayout/README.md for the Windows VM acceptance matrix. All previous configuration and feature modules are preserved.
