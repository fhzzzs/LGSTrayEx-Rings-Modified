# Battery Monitor — LGSTrayEx Rings Edition

Modified by [fhzzzs](https://github.com/fhzzzs). Based on [LGSTrayEx](https://github.com/strain08/LGSTrayEx), itself based on [LGSTrayBattery](https://github.com/andyvorld/LGSTrayBattery). GPL-3.0; see LICENSE, MODIFICATIONS.md and [upstream README](Docs/UPSTREAM-README.md).

Windows 11 x64. See [INSTALL.md](INSTALL.md) for the single build entry point and self-contained portable package. No Windhawk dependency. The source archive is not a prebuilt Windows binary.

Rings.9 keeps the ring renderer, charging animation, custom themes, alert sounds, device configuration, G HUB/HID/BLE/GIP/XInput/ASUS readers, and tests. Hardware identity links are retained when verified; ambiguous sources can be linked manually. Rings.9 adds an experimental built-in XAML Diagnostics provider for Start-adjacent native reservation, with heartbeat restoration and actual UI Automation geometry verification. No Windhawk dependency. Windows compilation and live verification are required; safe right-side positioning is the fallback.
